# Requirements

When the requirements are met the project is done.

1. [ ] client browser application (static app available via url)
2. [ ] create a lobby via shareable link
3. [ ] user configures default game settings via form before creating lobby
4. [ ] lobby hosts a game of Open Face Chinese Poker (see "./reference/open-face-chinese-poker-rules-engine-spec.md");
5. [ ] 2 to 4 players supported in any lobby
6. [ ] "AI lobby" option which can be used as a local-play option that does NOT engage the multiplayer service
7. [ ] internally configurable AI players (so you can customize AI player strength & style easily)
8. [ ] rules stay fixed for a lobby (to reconfigure game, create a new lobby)
9. [ ] game view is a minimal, 3D UI of the card game
10. [ ] unit tests for all features
11. [ ] end to end tests with playwright for features
12. [ ] support a local version of data-provider for testing & development that does not spend service quotas.
13. [ ] app deploys via github actions as a github repository page
